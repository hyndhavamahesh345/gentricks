# GENTRICKS

> Youth-driven technology, innovation, creator, community, and startup ecosystem bringing the next generation of builders, creators, entrepreneurs, and future leaders together.

## 🚀 Overview

Gentricks is an ecosystem designed for the next generation to connect, build, create, launch, and lead.

- **Stack**: React, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Architecture**: Classic Editorial Stacking-Sheet Layout
- **Identity**: Black (`#000000`), Electric Yellow (`#FFD000`), Pure White (`#FFFFFF`), Zinc (`#71717A`)

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
